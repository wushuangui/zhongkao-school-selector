# Handoff: V1-P0-05 静态「更新公告」区块（替代订阅推送）

## Scope
- **In**：仓库内静态 CHANGELOG（`data/changelog.json` + 同步的 `data/changelog-data.js`）；页脚上方常驻、可展开的「更新公告」；摘要覆盖校名、分数线、节点日期三类变更；展示最近发版日期；说明获取更新的方式是公众号 / 社群 / 重新打开 Pages 或单文件，而不是站内订阅。
- **Out**：订阅后端、登录、邮件/Webhook 推送（**D-1**）；重做 V1-P0-03 的 meta/页脚来源行；重做 V1-P0-04 FAQ；推荐档位与概率文案（**D-2**）；港澳/D 类专区（**D-3**）。

## Files / modules (suggested)
- `self-recruitment/data/changelog.json` — 人读与对照用的静态公告
- `self-recruitment/data/changelog-data.js` — 与 JSON 同内容的 `window.CHANGELOG_DATA`（页面不 `fetch`）
- `self-recruitment/js/changelog.js` — `escapeHtml` 后写入 `#changelog`
- `self-recruitment/index.html` — `#changelog` 容器与脚本引用
- `self-recruitment/css/style.css` — 与现有页脚/`.note` 同字号与颜色
- `self-recruitment/scripts/build_single.py`、`self-recruitment/deploy.ps1`、`.github/workflows/deploy-pages.yml` — 打进单文件与 Pages，避免运行时 404

## UI copy outline
- **Nav / labels**：不新增 Tab。页脚上方摘要：**更新公告 · 2026-11-18**（可展开）。
- **Body**：条目种类为「校名」「分数线」「节点日期」。展开后固定一段 **如何获取更新**：关注公众号或家长社群；或重新打开 GitHub Pages / Cloudflare Pages；也可索取新的单文件 HTML。本站不提供 App 内订阅、账号或推送。
- **Disclaimer / 风险提示**：公告只说明数据发版，不构成录取承诺；不出现录取概率 %。免责声明仍用现有页脚句。

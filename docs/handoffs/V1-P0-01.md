## UI copy outline

### Nav / labels
- 导航按钮：**填报指南**（`data-view="guide"`）
- 顶栏标题：**填报指南**
- Hash：`#guide`（与 `#rules` 规则弹窗并存）

### 四条路径（body）
1. **统招批次结构** — 自招 → 名额分配 → 第一批 → 第二批 → 二次划线（补录）→ 第三批；互斥以招考文件为准。官方：教育局一批公告等（`SCORES_DATA.sources`）。
2. **自招报名渠道** — 一类：「深圳市普通高中学校自主招生管理平台」网上报名；二类公办：招生学校现场报名。官方：教育局自招通知（`ZZZS_DATA.source`）。
3. **名额分配资格线含义** — 参与名额分配投档的最低资格线，按前三年同类录取线均值降 20 分划定；**≠** 第一批录取分数线。官方：报考指导手册 PDF（`sources.mee`）。
4. **补录 / 二批 / 三批指引** — 第二批为本市中职技工；二次划线：**资格线为填报门槛**，实际线 ≥ 资格线；第三批由省考试院组织。官方：`sources.batch2` / `second` / `batch3`。

### 每条路径结构
- 2～4 句说明（与 `rules.js`「录取分数线（非自招）」「报名规则」措辞对齐）
- **常见误区**（`guide-myth` 样式框 1 条）
- **规则说明**：按钮「打开规则说明 →」，对应 `rules.js` 小节（名称与 dt 一致）
- **官方查阅**：`target="_blank" rel="noopener"` 外链

### Disclaimer
- 页内：**以深圳市教育局、深圳招考网最新通知为准；本页为路径科普，不作录取承诺。**
- 与本站页脚既有免责声明一致（**D-2**：不出现录取概率 %）

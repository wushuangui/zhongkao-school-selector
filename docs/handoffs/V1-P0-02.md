## Scope
- In: 填报指南内年度时间轴；数据文件 `self-recruitment/data/timeline-2026.json` 与等价运行时 `timeline-data.js`；过期 / 进行中 / 未发生视觉区分；文案含「以教育局最新通知为准」；与四条路径互相锚点；CI / Cloudflare / 单文件打包一并发布。

## UI copy outline
- **标题**：2026 届关键节点
- **免责**：节点日期整理自本站规则说明中的公开表述，以教育局最新通知为准。
- **节点（有日期，与 rules.js 一致）**：自招报名 6/12–16；学校审核 6/17–22；公布入围 6/23；自招考核 7/4–5。
- **节点（无具体日）**：名额分配与统招志愿、出分与划线、二次划线与补录——文案为「见当年招考公告」。
- **状态**：已结束 / 进行中 / 未开始。
- **互链**：时间轴「对应路径」跳到填报指南卡片；每条路径有「看年度时间轴」。

## UI copy outline
- **页脚**：自主招生 {year}年 · 抓取 {fetchedAt} · 官方通知标题（链 `source.url`）；录取分数线同样展示年份与抓取时间，并列出各批次 `sources.*.url`；公办收费链市发改委。句末保留「控制线含义不同、收费以公示原文为准」。
- **各 Tab 常显一行**（折叠区外，class 沿用 `.note`）：
  - 自主招生：年份 · 抓取时间 · 教育局通知链接
  - 录取分数线：年份 · 抓取时间 · **当前批次**来源链接（切换批次时更新）
  - 收费标准：自招数据年份与抓取时间 · 市发改委收费标准链接
  - 填报指南：两行分别指向自招通知与分数线来源（本页无独立数据对象）
- **Disclaimer**：以主管部门与学校公示原文为准；不写录取概率。

# Handoff: V1-P0-04 FAQ 与规则同源维护机制

## Scope
- In: 规则条目只维护一份 `window.ZZZS_RULES`；规则弹层与填报指南 FAQ 都从该数组渲染；FAQ ≥ 8 且每条有 `#faq-n` 锚点；脚本说明同源关系，并在 Pages 构建前校验两边都引用同一全局、FAQ 不再手写第二份文案。
- Out: 订阅/账号后端、运行时拉取接口（D-1）；录取概率与冲稳保默认（D-2）；港澳或 D 类简版入口（D-3）；重做自招/分数线/学费三个 Tab。

## Files / modules (suggested)
- `self-recruitment/js/rules-data.js`（唯一文案）
- `self-recruitment/js/rules.js`、`self-recruitment/js/guide.js`
- `self-recruitment/index.html`、`self-recruitment/css/style.css`
- `self-recruitment/scripts/check_faq_rules.py`
- `.github/workflows/deploy-pages.yml`、`self-recruitment/deploy.ps1`、`self-recruitment/scripts/build_single.py`

## UI copy outline
- **Nav / labels**: 仍用「填报指南」。FAQ 标题「常见问答」，目录链到各条。高发两条置顶，名词与规则一致：「控制分（中考成绩控制线）」「名额分配控制线」。
- **Body / FAQ**: 问句用规则条目的名称，答句用同一条说明，不在 `guide.js` 再写一段。置顶说明点明：自招控制分只用于自主招生批次，与第一批录取分数线无关；名额分配控制线是资格线，按前三年同类录取线均值降 20 分划定，与当年第一批录取分数线不是同一条线。
- **Disclaimer / 风险提示**: 沿用指南已有「不构成录取承诺」与规则弹层「以官方文件和学校简章为准」。FAQ 不出现录取概率百分比。

## Decision compliance
- D-1: 纯静态脚本，无 `fetch`、无订阅后端。更新靠改 `rules-data.js` 再发版。
- D-2: FAQ 不写录取概率 %，不改推荐档位默认。
- D-3: 不新增港澳 / D 类简版或跨境向导；ACD 仍只是规则里已有的考生类别说明。
- D-4: 沿用现有导航、卡片与页脚，不另起产品名或主色。
